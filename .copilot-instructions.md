# Copilot Workspace Instructions

## SOLYNX Build Monitor Agent

Use the **SOLYNX Build Monitor** agent for questions about:
- Repository health and recent changes
- Build status, deployment state, or test results
- Branch conditions or pull request status
- Delivery risk assessment
- GitHub actions or CI/CD signals

### Quick Triggers
Simply ask Copilot:
- "Check the build status of [branch]"
- "Is [PR number] ready to merge?"
- "What's the health of this repo?"
- "Summarize any build issues"
- "Show delivery risk"

The agent will automatically gather evidence from git history, recent commits, workflow status, and branch state—then summarize what's healthy, blocked, or needs attention.

### Agent Location
`~/.config/Code/User/agents/solynx-build-monitor.agent.md`
